# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation required |
| needs-info | needs-info | Reporter information required |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Human implementation required |
| wontfix | wontfix | No action planned |

Use this mapping whenever a skill refers to a triage role.

# 完整列表与登录恢复

Status: complete

## 已确认规则

- 交易日期必填。仅交易日期和订单状态参与接口筛选。状态为空表示全部状态。
- 先通过网站接口读取全部分页并保存完整订单列表，再读取详情和图片。
- 列表请求失败、总数变化或订单身份重复时暂停，不下载图片。
- 登录失效时自动暂停。重新登录并恢复日期、状态查询后可继续原任务。
- 继续前核对查询和列表身份。成功且文件完整的订单不重复下载；已跳过订单保持跳过；失败、未完成或文件缺失的订单重试。
- SN码和发票必须齐全。证明材料不是必需项，有则下载。
- 沿用三笔订单并发、图片验证、逐张保存、失败回滚及四列清单规则。

- 现有测试入口和夹具：验证完整列表先于详情、无效日期、失败暂停、登录恢复和文件去重。

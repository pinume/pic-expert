# queryList 分页大小实测

日期：2026-10-09。用户要求直接读取接口，不按前端分页划分。

## 方法

在用户已登录的网站标签页内，用页面自己的登录令牌发出 queryList 的 JSON POST 请求。未输出令牌、订单内容或图片地址。未改变前端筛选控件，未下载图片。

筛选：beginTransDate=20260101，endTransDate=20261009，status=[]，current=0。此较宽日期范围仅用于只读上限探测，用户页面当前查询不变。

## 实际结果

| 请求 size | 返回条数 | 查询总数 | HTTP | success | 耗时 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 5358 | 200 | true | 未记录 |
| 100 | 100 | 5358 | 200 | true | 248 ms |
| 1000 | 1000 | 5358 | 200 | true | 817 ms |
| 10000 | 5358 | 5358 | 200 | true | 2461 ms |

## 结论

接口 size 不限于前端每页10条。实测接受10000，并能单次返回当前查询全部5358笔。由于结果总数不足10000，不能据此证明返回条数硬上限为10000，也不能断言接口没有上限。

本次只做接口读取，尚未修改插件的列表分页实现。若改为接口独立分页或一次读取全部，仍须保留条数、重复身份、完整列表及原断点检查。

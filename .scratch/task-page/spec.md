# 独立任务页面

## 需求

- 仿照 chinaums 的独立扩展标签页。从任意浏览器页面点击图标即可打开，不依赖订单网页保持前台。
- 独立任务页显示现有统计、日志、开始、暂停、继续、停止和清单控制。刷新网站不关闭任务页。
- 选择目标网站标签页，明确区分任务页和资料来源页面。多个网站标签页不自动猜测。
- 原下载规则、任务存储和断点恢复保持。关闭来源网站或刷新仍需恢复查询并继续。

## 最小方案与实施前审查

karpathy-guidelines：复用 popup.html、popup.js 作为独立任务页面，修改 manifest 图标入口，后台打开或聚焦已有页面；增加来源标签页选择。修正后台对独立扩展页消息的身份校验。

ponytail：不新增框架或任务执行器。仅增加 tabs 和 service.chinaums.com 的精确域名权限，以支持从其他网站启动。删除旧临时弹窗入口，不增加旧入口兼容分支。

涉及 manifest、后台控制身份校验、页面目标选择、样式、README，以及受影响的现有测试夹具。已有订单文件和 IndexedDB 数据不迁移或删除。

## 验收

- 图标可从任意页面打开独立任务页，再次点击聚焦已有页面。
- 来源网站标签页可选；未选择、已关闭或离开网站时明确提示。
- 新任务和继续使用选择的来源标签页，不误将任务页当作订单页。
- 独立扩展页能控制原任务，其他网站消息仍受到原任务标签页和 frame 校验。
- 页面刷新不关闭任务界面，完成统计和持久化日志能重新读取。

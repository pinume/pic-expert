# Pic Expert

Chrome Manifest V3 扩展：在用户已经登录、选择日期并完成查询后，处理**当前查询结果的全部分页**，批量下载完整订单的 SN 码、发票及存在的证明材料图片。

## 规则

- 扩展不负责登录、选择或调整日期、点击查询。包括详情返回阶段，均只使用用户已经查询的结果；不会修改查询条件或切换商户。返回后核对原条件、总条数、页码和订单集合；原结果未保留时停止，由用户手动恢复原列表。
- 处理当前查询结果全部分页：从第一页开始，结束时核对查询总条数。翻页须确认订单身份集合更新并稳定；遇到重复订单身份立即停止。
- 行内出现“材料修改”时整笔跳过。
- SN 码或发票任一缺失时整笔跳过，不下载半套资料。
- 每个参考号建立独立目录，文件名固定为 `SN码` 和 `发票`（保留实际图片格式的扩展名）。
- “证明材料图一”“证明材料图二”“证明材料图三”有图片时也下载，按原标签命名；空项目跳过，不重新编号。存在的图片会等待加载，识别不唯一或读取失败时整笔记为失败。
- 下载图片前按实际内容识别 JPEG、PNG、WebP、GIF、BMP；登录页、无法识别的内容或读取失败会整笔跳过或记为失败。
- SN码、发票及本单存在的证明材料均先验证再下载；任一下载失败时尝试清理该订单已生成的全部图片，无法清理的文件路径会记录到运行日志。
- 每次任务只生成一份 `下载清单.csv`，仅保留订单号、参考号、处理结果、原因四列；文件路径记录到运行日志。
- 默认保存到 Chrome 下载目录下的 `pic-expert/<任务时间>/`。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本仓库目录。
4. 打开目标订单页面，完成登录、日期选择与查询。
5. 点击扩展图标，选择“开始下载”。

## 页面适配与恢复

- 使用当前标签页的临时授权，探测可访问的 frame，仅对唯一的已查询订单列表启动任务；不增加永久网站访问权限。
- 支持 Element UI 分离表头/表体及固定列，避免重复扫描表格副本。主表操作入口不可见时，按订单号和参考号精确匹配固定列入口；入口不唯一时不打开详情。
- 银联商务 2026 采集详情按订单号核验身份，按图片容器识别“（必填）SN码照片”和“（必填）发票图片”，排除占位图，并单独识别三类证明材料图。
- 门户详情的原生返回入口可能跳转到其他模块。扩展使用记录的 frame 路由返回原列表，仅核对保留的条件、总条数和订单集合；不会操作日历或查询按钮。必要时优先用页码按钮或跳页输入框返回原页，无直接控件时逐页返回。原查询结果丢失或核对失败立即停止。
- 运行期间不要切换页面或修改查询条件；发生变化时扩展会停止。
- 关闭扩展弹窗不影响任务。页面刷新或任务中断后可点击“暂停任务”保存断点，手动返回相同查询后点击“继续上次任务”；“停止任务”结束当前批次并生成清单。清单下载失败可点击“重试下载清单”。
- 弹窗中展开“运行日志”可查看和复制最近 500 条记录，包含时间、步骤、订单身份、下载路径及错误；关闭弹窗后日志仍保留。完整日志按条持久化，可点击“导出完整日志”，每 5,000 条生成一个编号文本文件；开始新任务后弹窗切换显示新任务。

## 大批量处理与断点

- 月份和查询条件由用户操作；每批只处理已查询结果，扩展不会自动跨月查询。
- 点击“暂停任务”后等待当前订单下载并返回列表；需要中断当前等待时再次点击“立即暂停当前等待”。未完成图片会清理，失败和残留路径会记录。
- 继续前手动恢复原查询，扩展核对条件、总条数和断点页订单集合。核对通过才继续，沿用同一任务编号和目录；完成且下载记录确认文件仍存在的订单不重复下载，失败订单可重试。已跳过的订单在同一任务内不重复处理。
- IndexedDB 独立保存订单、下载记录和完整日志；弹窗只读取统计及最近 500 条日志。旧版本任务数据自动迁移，迁移失败时保留原数据。
- 同一订单最多并发读取两张图片，全部验证后再逐张下载；订单页面操作仍串行。图片网络读取临时错误最多额外重试一次，身份和格式错误不重试。
- 删除每笔详情的固定等待，仅等待已识别详情中的图片就绪。下载优先监听完成事件，并周期补查状态以覆盖事件遗漏和后台重启。
- 结束时只生成四列清单，并记录总数、结果统计和历时。失败任务继续后，结束清单会覆盖同一任务目录下的清单文件。
- 断点只针对上次任务；不同月份的新任务不会自动跨批次去重。站点登录失效、原查询丢失或数据变化时，需要用户处理后重新核对。

## 验证

扩展没有运行时依赖。测试使用 Node.js 自带运行器和开发依赖 fake-indexeddb（仅模拟 IndexedDB，不随扩展运行）。首次验证先安装锁定的测试依赖：

```bash
npm ci
```

再执行：

```bash
npm test
```

同时可以执行：

```bash
npm run check
```

真实站点 DOM 可能调整；如页面字段名、详情弹窗或分页控件发生变化，需要同步更新页面适配逻辑。

自动化测试覆盖 iframe 选择、真实页面结构 DOM 夹具、多页扫描、返回失败停止、防重入、配对回滚和清单恢复，也覆盖暂停续传、文件丢失、旧数据迁移、两万条 IndexedDB 存储、并发读取及完整日志分段导出。IndexedDB 测试使用模拟实现；云浏览器无法加载解压扩展，未完成真实 Chrome 扩展 E2E，大批量下载速度仍需在本地 Chrome 验证。

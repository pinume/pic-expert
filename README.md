# Pic Expert

Chrome Manifest V3 扩展：在用户已经登录、选择日期并完成查询后，处理**当前查询结果的全部分页**，批量下载完整订单的 SN 码图片与发票图片。

## 规则

- 扩展不负责登录、选择日期或发起查询。
- 处理当前查询结果全部分页。
- 行内出现“材料修改”时整笔跳过。
- SN 码或发票任一缺失时整笔跳过，不下载半套资料。
- 每个参考号建立独立目录，文件名固定为 `SN码` 和 `发票`（保留原扩展名）。
- 每次任务只生成一份 `下载清单.csv`，记录订单号、参考号、处理结果、原因和下载文件路径。
- 默认保存到 Chrome 下载目录下的 `pic-expert/<任务时间>/`。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本仓库目录。
4. 打开目标订单页面，完成登录、日期选择与查询。
5. 点击扩展图标，选择“开始下载”。

## 验证

项目没有运行时依赖。使用 Node.js 自带测试运行器：

```bash
npm test
```

同时可以执行：

```bash
npm run check
```

真实站点 DOM 可能调整；如页面字段名、详情弹窗或分页控件发生变化，需要同步更新页面适配逻辑。
